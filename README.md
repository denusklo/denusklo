# Hi, I'm Den Kong

I'm a Laravel fullstack developer from Malaysia. Lately I've been building tools for games and the browser.

## Projects

- [HoopLandHelper](https://github.com/denusklo/HoopLandHelper): A Python/OpenCV tool that reads Hoop Land's shot meter from a live phone screen feed and times shot releases over ADB.
- [autospinner](https://github.com/denusklo/autospinner): A vanilla JavaScript Chrome extension that reads the Tower of Saviors simulator's board, finds an orb-matching path with beam search, and drags the orb automatically.
